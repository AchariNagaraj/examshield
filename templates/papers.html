SECURITY PROCESS

What happens when you secure the paper?

01

Encrypt

The plaintext examination paper is protected using AES-256-GCM.

02

Wrap

The AES key is wrapped using each center's RSA public key.

03

Watermark

A center-specific HMAC watermark is embedded to support traceability.

04

Sign

The board signs the canonical package metadata using RSA-PSS.
